Алгоритм решения







Создаётся класс Product с приватными полями(\_id, \_name, \_price, \_availability, \_category). В нём создаётся Конструктор по умолчанию, конструктор с полями, конструктор копирования, свойства для каждого из полей, перегруз метода ToString().



В классе StoreManager создаются разные методы. В методе GenBin передаётся строка с путём до бинарного файла, список объектов класса Product. Проверка правильно введённого пути к файлу. Открывается файл в режиме записи. В самом начале бинарного файла записываю количество элементов. Затем через цикл foreach прохожу по всем элементам списка и записываю их значения в бинарный файл. Закрытие файла.



#### В метод из списка целых объектов "ReadBin" передаётся путь к файлу. Проверяется путь к файлу. Открывается файл в режиме чтения. Считывается первое целочисленное значение int. С помощью цикла for считывает данные из файла и на их основе создаёт новый объект p и добавляет их в конец списка "products.Add(p)". Возвращает в main список из всех элементов БД.



#### В метод из списка целых объектов "GetProduct" передаётся список объектов. С помощью LINQ-запроса .Where, проверяется свойство Availability у каждого объекта. Если совпало то записываются в список "ToList()", затем возвращаются в Main для дальнейшей работы.



#### В метод из списка целых объектов "GetSort" передаётся список объектов. Происходит упорядочивание набора с помощью ".OrderBy" по возрастанию их значения Price. Затем превращение в список "ToList()". Возвращение списка  в main.



#### Два отдельных метода поиска Min и Max, в них передаётся список с объектами. Поиск Min или Max ".Min(x => x.Price)", возвращение строки к main.



#### В метод AddProducts передаётся ссылка на список, целый объект класса Product. Происходит добавление полей в конец списка. products.Add(item)



#### В метод RemoveProducts передаётся ссылка на список, ID товара который надо удалить. Если ID совпадает, удаляется объект из списка с совпадающим ID. ".RemoveAll(x => x.ID == targetID)"
